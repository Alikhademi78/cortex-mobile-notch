# Cortex Mobile Notch

همدم هوش مصنوعی زنده و متن‌باز روی ناچ گوشی اندروید؛ متصل به **Gemini Live** (مکالمه صوتی بلادرنگ) و چت متنی شناور.

ساخته شده توسط **کورتکس (Cortex)** • اینستاگرام: [Cortex.fa](https://www.instagram.com/cortex.fa)

---

## امکانات کلیدی

- **مکالمه صوتی زنده با Gemini Live:** با نگه داشتن ناچ، مکالمه صوتی دوطرفه و بلادرنگ با مدل `gemini-3.8-live` شروع می‌شود و سیستم ضد اکو هنگام صحبت کردن دستیار، میکروفون را به‌صورت خودکار مدیریت می‌کند تا صدای اسپیکر اکو نشود.
- **پنجره چت متنی شناور:** با دو ضربه سریع روی ناچ، پنجره چت متنی باز می‌شود تا در هر برنامه‌ای بدون خارج شدن از صفحه بتوانید تایپ کنید و پاسخ بگیرید (دارای دکمه کپی سریع پاسخ و پاک کردن تاریخچه).
- **انتخاب مدل چت متنی:** امکان انتخاب بین ۴ مدل برای چت متنی در تنظیمات:
  - `Gemini 3.5 Flash Lite` (سریع و اقتصادی — پیش‌فرض)
  - `Gemini 3.8 Flash` (هوشمند و دقیق)
  - `Gemini 4 Hydrogen` (نسل جدید)
  - `Gemini 4 Argon` (تفکر عمیق)
- **۵ تم نوری و رنگ چشم زنده:** طلایی کورتکس، آبی سایبرپانک، بنفش نئونی، سبز هکری و قرمز گیمینگ (اعمال آنی روی ناچ و کل رابط کاربری).
- **۵ صدای مختلف برای مکالمه زنده:** `Charon`، `Puck`، `Fenrir`، `Aoede` و `Kore`.
- **کالیبراسیون ناچ برای تمام گوشی‌ها:** اسلایدرهای تنظیم عرض، ارتفاع، فاصله عمودی و جابه‌جایی افقی برای هماهنگی دقیق با ناچ یا دوربین سلفی هر مدل گوشی.
- **شخصیت و پرامپت قابل ویرایش:** امکان تغییر لحن، نام و دستورالعمل رفتاری دستیار.
- **مصرف باتری بسیار پایین:** در حالت سکون بدون انیمیشن‌های اضافه، و با خاموش شدن صفحه نمایشگر کاملاً متوقف می‌شود.
- **حریم خصوصی کامل:** اپ هیچ سرور واسطی ندارد؛ کلید API فقط روی حافظه محلی خود گوشی ذخیره می‌شود (`allowBackup="false"`) و مستقیم به سرورهای رسمی گوگل وصل می‌شود.

## راهنمای راه‌اندازی سریع (برای کاربران)

1. فایل نصبی (`CortexNotch-v1.0.0.apk`) را از بخش **Releases** دانلود و نصب کنید.
2. برنامه را باز کرده و مجوز **نمایش روی سایر برنامه‌ها (Display over other apps)** و **میکروفون (Microphone)** را تایید کنید.
3. وارد تب **کلید و راهنما** شوید، روی **دریافت کلید رایگان** بزنید و یک کلید رایگان از [Google AI Studio](https://aistudio.google.com/app/apikey) بسازید و در برنامه ذخیره کنید.
4. *(در صورت محدودیت منطقه‌ای یا اینترنت، قبل از شروع مکالمه VPN مناسب روشن کنید.)*
5. از تب **ظاهر و ناچ** ابعاد ناچ را دقیقاً روی دوربین گوشی خود تنظیم کنید و از کورتکس لذت ببرید!

## ساخت از سورس کد (Build from Source)

### پیش‌نیازها
- **Android Studio** (نسخه Ladybug یا جدیدتر) یا **JDK 17**
- **Android SDK** (`compileSdk = 35`, `minSdk = 26`)

### مراحل بیلد با Gradle
```bash
git clone https://github.com/Alikhademi78/cortex-mobile-notch.git
cd cortex-mobile-notch
./gradlew assembleDebug
```
یا برای ساخت نسخه Release:
```bash
./gradlew assembleRelease
```
